# Projects

BISA

BISA stands for "Bio-informatics student-assistant" and is a passion project made to simplify the shift planning for student-assistants at the University of Applied Sciences in Leiden.

HTML - CSS - JS - Python - Django - SQLite - HTMX

Stravis

After using Strava to track my sports activities for about 3 years, I created a way to visualize my activities. Hence the name "Stravis". This Django application allows the user to connect to their Strava account and synchronize their activities. Total statistics and other customizable plots are calculated and displayed. D3.js is used to create the "Activity calendar heatmap" and other interactivity. Bokeh is used to create most plots.

HTML - CSS - JS - Python - Django - SQLite - D3 - Bokeh

Erato

Developed in a group of students. The application handles grade administration for students. The client had a lot of specific requirements, which no other grade administration system satisfied. I was primarily responsible for communicating with the client and leading meetings, which I thoroughly enjoyed! The application was never truly finished, because the client's wishes were too much for us to complete in 7 weeks.

HTML - CSS - JS - Python - Django - PostgreSQL - HTMX - Docker

MasterBlast

This Django web app is a wrapper for NCBI's BLAST. The application uses Biopython to interact with the BLAST API and stores the BLAST job in a PostgreSQL database. The user can run jobs asynchronously, view old jobs and add other users as friends in order to share BLAST jobs with them. Celery is used in conjunction with RabbitMQ to run the jobs asynchronously.

HTML - CSS - JS - Python - Biopython - Django - PostgreSQL - Docker - Celery - RabbitMQ

Reedsnake

A Snakemake pipeline for the analysis of DNA sequencing data. Wrote custom scripts for the quality control and trimming of the reads and used existing tools to perform both a reference-based and a de novo assembly.

Python - Snakemake - Bash

COGselect

The application that made me fall in love with web development! The application is very simple, allowing the user to connect to a PostgreSQL database and download clusters of orthologous genes (COGs). The application visualizes these clusters and allows filtering, so the user can select clusters that they deem interesting.

HTML - CSS - Python - Flask - PostgreSQL
